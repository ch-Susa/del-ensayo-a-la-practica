# del-ensayo-a-la-practica
Repositorio dedicado a documentar el proceso de aprendizaje y aplicación práctica de conocimientos en desarrollo de software.

Aplicar los conocimientos adquiridos durante el proceso formativo mediante el diseño y desarrollo de una nueva página web, integrando buenas prácticas de programación, estructura, diseño y organización del proyecto para transformar los conceptos teóricos en una solución web funcional.
